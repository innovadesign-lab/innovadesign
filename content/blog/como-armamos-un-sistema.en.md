## Fewer pieces, more rules

We start with what already repeats: surface color, text color, one face for titles and another for body, and the space between blocks. If that is not named, the library only hides the inconsistency.

## What the first handoff includes

- Color, type, and space tokens.
- Button, field, and link, with states.
- One real page built from those pieces.

What does not belong in the first handoff is the component that appears only once. That gets documented when it repeats.

## The test

Someone else on the team has to be able to build a new screen without asking. If they need a call to know which gray to use, the system is not there yet.
